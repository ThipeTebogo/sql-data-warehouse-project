# Power BI Dashboard

**The dashboard is structured into four analytical domains:**
  1. Executive Overview
  2. Product & Profitability Analysis
  3. Customer Segmentation
  4. Operational Performance

## **Key KPIs include:**

Total Revenue

Gross Profit

Gross Margin %

Revenue Growth %

Average Order Value

Late Delivery %
