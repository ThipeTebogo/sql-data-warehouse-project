# Power BI Dashboard
The dashboard transforms cleansed CRM and ERP data into actionable business insights across revenue, profitability, customer behavior, and operational efficiency,
The objective was not only to visualize data, but to design a business-ready analytics solution built on proper data modeling and KPI standardization.


## **The dashboard is structured into four analytical domains:**
  1. Executive Overview
  2. Product & Profitability Analysis
  3. Customer Segmentation
  4. Operational Performance

## **Key KPIs include:**

Total Revenue

Gross Profit

Gross Margin %

Revenue Growth %

Average Order Value

Late Delivery %
